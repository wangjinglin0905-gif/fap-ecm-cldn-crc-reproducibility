# Candidate scripts not used for R1 inference

These two files were supplied with the AJCR v5.5 candidate revision and are retained only to document the audit trail.

- `fibroblast_content_sensitivity_analysis_candidate.py` did not implement the final standard partial-Spearman workflow and was not used for reported R1 values.
- `satterthwaite_check_candidate.R` was a model template without the archived analysis data; it did not by itself verify the manuscript values.

Use the audited scripts in `scripts/locked_release/R1_audited/` instead.
